# MCP BOT

MCP BOT is the CIBN Micro-Finance Certification Program exam-prep companion and an education-domain child product of InstituteGPT.

## Canonical position

- Parent product: `carbonactual/institutegpt`
- Canonical ecosystem authority: `carbonactual/carbonactual`
- Constitutional authority: `carbonactual/hapi-world/CANON.md`
- Intelligence/orchestration: `carbonactual/abba`
- Domain: education and certification preparation

MCP BOT specializes the education workflow. It does not create a second identity, authority, graph, event, evidence, state, value, or constitutional system.

## Conformance

The shared Carbon Actual contracts remain authoritative for identity, authority, intent, capability, events, evidence and state. Education-specific workflows belong here and remain reusable only when they do not redefine shared semantics.

See `CARBON_ACTUAL_CONFORMANCE.md` and `architecture/product-inheritance.json`.
